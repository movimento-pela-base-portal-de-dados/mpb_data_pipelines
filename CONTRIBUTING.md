# Contribuição

- Alterações entram por Pull Request.
- A branch `main` deve ser protegida contra push direto.
- CI precisa estar verde antes do merge.
- Conectores devem ser reexecutáveis e evitar duplicação de dados.
- Segredos e credenciais não são versionados.
- Mudanças de schema e contratos devem ser explícitas no PR.
- Decisões arquiteturais relevantes devem ser registradas em `docs/`.
